## 3. Реализация лабораторной работы 5

### 3.1. Генерация числовых рядов

Реализованы следующие функции:

- `random_series()` — случайные числа из равномерного распределения;
- `sine_series()` — синусоидальный ряд с шумом;
- `trend_series()` — линейный тренд с шумом.

Для воспроизводимости результатов используется параметр `seed`.

### 3.2. Расчёт статистических показателей

Модуль `stats.py` содержит функции:

- `mean()` — среднее арифметическое;
- `median()` — медиана;
- `spread()` — размах;
- `summarize()` — сводная статистика.

Статистические показатели рассчитываются без библиотек
`statistics`, `numpy` и `pandas`.

### 3.3. Скользящие средние

Реализованы:

**SMA — Simple Moving Average**

Простая скользящая средняя. Вычисляется с помощью бегущей суммы.

Временная сложность: O(n).

**CMA — Centered Moving Average**

Центрированная скользящая средняя.

Используется нечётный размер окна.

**EMA — Exponential Moving Average**

Экспоненциальная скользящая средняя:

EMA[0] = x[0]

EMA[i] = alpha * x[i] + (1 - alpha) * EMA[i-1]

где 0 < alpha <= 1.

### 3.4. Работа с файлами

Приложение поддерживает:

- загрузку числового ряда из TXT;
- загрузку числового ряда из CSV;
- загрузку числового ряда из JSON;
- сохранение ряда в JSON;
- экспорт исходного ряда в CSV.

## 4. Расширение лабораторной работы 5.1

### 4.1. Использование deque

В проект добавлен модуль `deque_average.py`.

`deque` — двусторонняя очередь из модуля `collections`.

Основные операции:

- `append()` — добавление справа;
- `appendleft()` — добавление слева;
- `pop()` — удаление справа;
- `popleft()` — удаление слева.

Операции добавления и удаления с концов выполняются за O(1).

Реализованы:

- `simple_moving_average_deque()`;
- `centered_moving_average_deque()`;
- `exponential_moving_average_deque()`.

Для SMA используется очередь и бегущая сумма.

Временная сложность SMA: O(n).

Дополнительная память: O(k), где k — размер окна.

### 4.2. Измерение производительности

В модуле `moving_average.py` реализована функция:

`benchmark_moving_average(data, window, repeats=1000)`

Для измерения времени используется `time.perf_counter()`.

Сравниваются две реализации SMA:

1. SMA через исходный список.
2. SMA через deque.

Среднее время одной операции:

T = (t_end - t_start) / repeats

Результат содержит:

- время выполнения list;
- время выполнения deque;
- отношение list/deque.

Сравнение запускается аргументом `--benchmark`.

## 5. Лабораторная работа 5.1 — вариант 13

### 5.1. Условие задания

Сформировать числовой ряд из 2000 значений экспоненциального
распределения:

```python
random.expovariate(lambd=0.5)
```

Реализовать дополнительные показатели:

- коэффициент асимметрии (skewness);
- эксцесс (kurtosis).

Расчёты выполнять вручную, без библиотеки scipy.

Реализовать:

- SMA через list;
- SMA через deque;
- EMA.

Краевой случай:

Все значения исходного ряда должны быть строго положительными.
Статистические показатели не должны содержать NaN и inf.

### 5.2. Генерация данных

Функция `exponential_series()` генерирует экспоненциальное
распределение с параметром lambda = 0.5.

Для воспроизводимости применяется `random.Random(seed)`.

### 5.3. Коэффициент асимметрии

Асимметрия характеризует степень несимметричности распределения.

Формула:

skewness = m3 / m2^(3/2)

где:

m2 = sum((x - mean)^2) / n

m3 = sum((x - mean)^3) / n

### 5.4. Эксцесс

Эксцесс характеризует форму распределения относительно
нормального распределения.

Формула:

kurtosis = m4 / m2^2 - 3

где:

m4 = sum((x - mean)^4) / n

Используется эксцесс с вычитанием 3.

### 5.5. Проверка краевого случая

Для проверки используется `math.isfinite()`.

Проверяется:

- отсутствие отрицательных чисел и нулей;
- отсутствие NaN;
- отсутствие бесконечных значений.
